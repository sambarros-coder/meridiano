# Meridiano

Portal de notícias e informações econômicas. Agrega notícias de outros veículos via RSS, sempre com crédito e link para a fonte original (título, trecho curto, veículo, data e link; nunca o texto completo).

## Rodar localmente

```bash
npm install
npm run dev
```
